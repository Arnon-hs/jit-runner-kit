# Support

`jit-runner-kit` is a pre-1.0 volunteer-maintained project. Support is best effort; there is no guaranteed response or resolution time.

Use:

- GitHub Discussions for setup and usage questions;
- GitHub Issues for reproducible bugs and accepted feature proposals;
- the private process in [SECURITY.md](SECURITY.md) for vulnerabilities.

Include the toolkit commit or version, controller operating system, OpenTofu or Terraform version, provider region and server type, relevant redacted logs, and the expected versus actual behavior. Never post credentials, JIT configuration, infrastructure state, private keys, private repository names, or production identifiers.

Cloud account, GitHub billing, and general infrastructure administration remain the operator's responsibility.
